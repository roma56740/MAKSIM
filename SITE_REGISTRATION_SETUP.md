# Регистрации на сайте через Railway

Бот запускает защищённый API вместе с обычным Telegram-ботом. Регистрации сохраняются в основной SQLite-базе, поэтому сайт и бот могут находиться в разных сервисах Railway.

## Переменные бота

- `SITE_API_ENABLED=1`
- `SITE_REGISTRATION_SECRET=длинный-случайный-секрет`
- `DB_PATH=/data/bot.sqlite3`
- `PORT` Railway задаёт автоматически

Подключите к сервису бота Railway Volume с точкой монтирования `/data`, чтобы регистрации и остальные данные сохранялись после обновления сервиса.

После публикации включите для сервиса бота публичный домен Railway. Проверка работы:

`https://домен-бота.up.railway.app/health`

Страница должна вернуть `{"ok": true, ...}`.

## Переменные сайта

- `SITE_REGISTRATION_API_URL=https://домен-бота.up.railway.app`
- `SITE_REGISTRATION_SECRET=тот-же-секрет-что-у-бота`

Новая анкета отправляется в API бота. Бот сохраняет её, присылает администраторам карточку с кнопками «Открыть доступ» и «Отклонить», а сайт автоматически получает решение.

Старые настройки `SITE_REGISTRATIONS_PATH` и `SITE_REGISTRATION_HOOK_URL` оставлены как запасной режим для прежней схемы.
