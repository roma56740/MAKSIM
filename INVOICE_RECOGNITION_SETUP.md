# Распознавание накладных

Обязательная переменная Railway:

```env
OPENAI_API_KEY=ваш_ключ
```

Для накладных бот сначала использует `OPENAI_INVOICE_MODEL`, если она задана.
Иначе применяется уже настроенная и доступная проекту `OPENAI_MODEL`. Это важно:
бот не должен терять распознавание из-за недоступной аккаунту модели.

Необязательные настройки:

```env
OPENAI_INVOICE_MODEL=gpt-4o-mini
OPENAI_INVOICE_FALLBACK_MODEL=gpt-4o
OPENAI_INVOICE_DOUBLE_CHECK=1
```

- `OPENAI_INVOICE_MODEL` — основная модель распознавания.
- `OPENAI_INVOICE_FALLBACK_MODEL` — запасная модель, если основная временно недоступна.
- `OPENAI_INVOICE_DOUBLE_CHECK=1` — контрольная перепроверка. Для фото она включается
  автоматически, даже если переменная не добавлена.
- `OPENAI_INVOICE_IMAGE_DETAIL=original` можно включить только для модели, которая
  поддерживает исходное разрешение. По умолчанию бот сам выбирает безопасное значение.

Поддерживаются PDF, JPG, PNG, WEBP, HEIC, HEIF, XLSX и XLS. Для HEIC/HEIF бот
автоматически делает совместимую JPEG-копию перед распознаванием.

Если API не принял ключ, достиг лимита или не дал доступ к модели, в базе и в
админ-панели сохраняется безопасная конкретная причина. Сам файл при этом не теряется.

После изменения переменных нужно выполнить Deploy/Restart сервиса Railway.

Принятый результат всегда остаётся под контролем администратора: бот показывает все
позиции, сумму до скидки, скидку и итог к оплате. Администратор может исправить строки,
запустить распознавание заново или отклонить документ.
